# FF3 shops — every shopkeeper, and what they stock

Generated by `tools/ff3-shop-catalog.mjs`. Verified against the running game
by `tools/ff3-shop-probe.mjs --all` (names AND prices, 0 mismatches);
pinned by `tools/check-ff3-shops.mjs`.

This is the ROM's own table, not ff3mmo's `src/data/shops.js` — that one is
the game's own design and is deliberately different.

A shop is a shopkeeper NPC. `tools/ff3-shop-sweep.mjs` established which ids
open one by patching a shopkeeper's id and talking to all 256.

| table | where | per entry |
|---|---|---|
| shop record ptr | bank 44 `$8200`, file `0x58210` | 2 bytes LE, by NPC id |
| item price | bank 16 `$9E00`, file `0x21e10` | 2 bytes LE |
| item name ptr | bank 24 `$8800`, file `0x30810` | 2 bytes LE |

A record is `[kind][up to 8 item ids]`, ended early by a `00`.
Kind bytes: `7` Weapons, `8` Armor, `9` Items, `10` Magic.

⛔ 232, 239, 244 and 250 have well-formed records and open **nothing**, so the
shop id list is measured rather than derived from "has a record".
