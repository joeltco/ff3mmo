# FF3 — every name in the item table

Generated by `tools/item-catalog.mjs` from the tables decoded in
`tools/lib/ff3-shops.mjs` (pinned by `tools/check-ff3-shops.mjs`).

Name pointers: bank 24 `$8800`, file `0x30810`, 2 bytes LE per id,
pointing at `[icon byte][name][00]` in bank 30 at `$C000`.  
Prices: bank 16 `$9E00`, file `0x21e10`, 2 bytes LE per id.

**243 ids carry a nonzero price.**

⛔ Some glyph bytes have no entry in the decoder, so a few names read short
(`Bzzard` for Blizzard). The running game draws the same gap as a space, so
this is the decoder's table being incomplete, not the ROM.

⛔ Eight ids are NOT items: their name pointers land on junk and the game
draws no row for them at all (measured — `item-verify.mjs --game 3 --batch 1`).
