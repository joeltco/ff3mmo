# FF2 shops — every one of the 28, and what it stocks

Generated by `tools/ff2-shop-catalog.mjs`. Verified against the running game
by `tools/ff2-shop-probe.mjs --all` (names AND prices, 0 mismatches);
pinned by `tools/check-ff2-shops.mjs`.

A shop is an OBJECT TYPE, not a tile: talking to object type 192-219 opens
one. `tools/ff2-type-sweep.mjs` established that by standing all 256 types
next to the party. The four types after the shops are special:

| type | what it is |
|---|---|
| 220 (`0xDC`) | FERRY |
| 221 (`0xDD`) | AIRSHIP |
| 222 (`0xDE`) | INN |
| 223 (`0xDF`) | NOTHING |

| table | where | per entry |
|---|---|---|
| shop record | CPU `$860D` bank 14, file `0x3861d` | 8 bytes = 4 x (item, price code) |
| price by code | CPU `$8000` bank 14, file `0x38010` | 2 bytes LE |
| item name ptr | CPU `$8200` bank 10, file `0x28210` | 2 bytes LE |

The second byte of an entry is a **price code**, not a price: the same code
gives the same price for different items (`0xF2` is 500 G for both Axe and
Mace), and it indexes the table above.
