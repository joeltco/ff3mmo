# FF1 shops — every id, what it stocks, what it charges

Generated by `tools/ff1-shop-catalog.mjs`. Verified against the running
game by `tools/ff1-shop-probe.mjs --all`; pinned by `tools/check-ff1-shops.mjs`.

A tile's property byte 1 is the shop id (`$CEB0`), so this table is what
any door in any town opens. See `tools/lib/ff1-shops.mjs` for the listings.

| table | where | per entry |
|---|---|---|
| shop kind | CPU `$EBB5`, file `0x3ebc5` | 1 byte, `& 0x07` |
| shop record ptr | CPU `$8300` bank 14, file `0x38310` | 2 bytes LE |
| item price | CPU `$BC00` bank 13, file `0x37c10` | 2 bytes LE |
| item name ptr | CPU `$B700` bank 10, file `0x2b710` | 2 bytes LE |

The record is at most 5 bytes and ends at the first `00`.
INN and CLINIC records are not item lists — they are a 16-bit price.
